# Wedding Card

A Telugu wedding invitation site built with React 19, Vite and Tailwind CSS v4.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Make it yours

Edit `src/config.js`. It holds the names, parents, dates, events, traditions,
photos, RSVP settings and music.

- **Photos:** put them in `public/img/` and list each one in `photos` with its
  real pixel width and height (`w`, `h`) so the card keeps its shape. Optional
  `position` (e.g. `'50% 20%'`) controls the crop focus.
- **Music:** `public/audio/wedding-bgm.m4a` is an original nadaswaram rendition
  of the pallavi of Thyagaraja's "Seetha Kalyana Vaibhogame" (raga Kurinji,
  Khanda Chapu), with ottu drone, thavil and talam, generated by
  `scripts/make-music.py`. It starts when a guest taps "Open Invitation" and
  loops. To use a recording instead, put an mp3/m4a in `public/audio/` and point
  `music` at it. Only use recordings you have the rights to.
- **Blessings:** the invocation, Venkateswara line and deity text are in
  `blessings` in `src/config.js`.
- **Page title and description:** update them in `index.html`.

## Deploy (GitHub Pages)

Every push to `main` builds the site and publishes it to GitHub Pages
(`.github/workflows/deploy.yml`). Paths are relative, so it works at
`https://<user>.github.io/<repo>/`.

## RSVP

GitHub Pages can't receive form submissions, so RSVPs go to a form service.
Create a free form at [Formspree](https://formspree.io), copy its endpoint
(`https://formspree.io/f/...`) into `rsvp.endpoint` in `src/config.js`, and push.
Responses arrive by email and in the Formspree dashboard. Until an endpoint is
set, the form tells guests that online RSVP isn't open yet.
